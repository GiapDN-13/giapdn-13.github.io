Transit Sleep Agent

AI Agent In Progress

AI Agent định vị GPS kết hợp phân tích Traffic ETA từ Google Maps API theo thời gian thực. Tự động tính toán thời điểm đánh thức tối ưu, chống ngủ quên lố trạm trên xe bus/tàu — khác biệt hoàn toàn với geofencing tĩnh.

LangChain FastAPI Google Maps API Flutter
Repository

📖 README.md

Vấn đề: Các app báo thức hiện tại chỉ dùng Geofencing tĩnh (bán kính cố định) — không phản ánh được tình trạng kẹt xe thay đổi liên tục.

Giải pháp: AI Agent liên tục gọi Google Maps Directions API để lấy ETA thực tế, so sánh với thời gian ngủ mong muốn, và tự động trigger alarm khi cần.

Kiến trúc:

Flutter App (GPS) → FastAPI Backend → LangChain Agent
  ↕ Google Maps Directions API (real-time ETA)
  ↕ Push Notification Service (FCM)

Cách chạy:

$ git clone https://github.com/GiapDN-13/transit-sleep-agent
$ cd backend && pip install -r requirements.txt
$ uvicorn main:app --reload

Agentic RAG Qdrant GPT-4o Streamlit

📖 README.md

Giải pháp: Nâng cấp thành Agentic RAG — Agent tự quyết định khi nào cần retrieval, khi nào dùng Calculator Tool, khi nào tổng hợp từ nhiều nguồn.

Kiến trúc:

User Query → Agent Planner (LLM)

  ├── Tool: Score Calculator

→ Synthesized Answer → Streamlit UI

Cách chạy:

$ git clone https://github.com/GiapDN-13/agentic-rag-edu
$ pip install -r requirements.txt
$ streamlit run app.py
